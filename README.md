
# Nuxt Minimal Starter

## Setup

Instala las dependencias:

```bash
pnpm install
```

## Servidor de desarrollo

Inicia el servidor en `http://localhost:3000`:

```bash
pnpm dev
```

## Producción

Construye la aplicación para producción:

```bash
pnpm build
```

Previsualiza la build de producción localmente:

```bash
pnpm preview
```
